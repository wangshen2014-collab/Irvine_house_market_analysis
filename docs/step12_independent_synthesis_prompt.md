必须防止的推理错误：

- 人口增长不是净迁入，家庭增加不等于目标买家；DOF住房单位法、SCAG容量与供给不得重复当独立需求加成。ACS五年窗、MOE和城市／社区代理边界保留。
- 居民均值不是边际买家；HMDA不含全现金，缺融资记录不是全现金证据；姓名／族裔不推资金来源。AI、工资、股票、RSU和住房净值的共同风险不可拆散后重复加成。
- 学校成绩不是教学因果贡献或保证入学。核官方目录分母、统一指标覆盖及家长材料；不强行唯一排名。学校／经纪人“列名”不等于完成深度或独立覆盖。
- 项目母子期、容量／批准／许可／开工／开盘／交付不得相加。未来累计套数不与一年成交直接称库存月数；公寓不是四卧无共墙直接供给；无可靠分母不造增长率。
- ZHVI不是严格同品质重复成交，Orchard Hills不等于Reserve，县级不是目标户型；pending存量不是新签约流量。挂牌租金、MLS关闭与真实租约分开，三卧租／四卧买升级分开。
- 本金在现金流中是支出，在经济成本中转权益；税／Mello-Roos／HOA／保险／维护分别处理。旧税单不代新税基，未知保险等不填零，补充税不重复累计。
- 等月供购买力不是均衡房价或买租临界价；全国锁定模型不直接套Irvine；历史相关不是因果弹性。稳定降息、衰退、高息持续和目标供给增加需联合解释收入、股票、信贷、租金与卖方供给，不赋无依据概率。
