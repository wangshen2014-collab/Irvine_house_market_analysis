# Research instructions

This is an independent public-data housing-market project. Read README.md, STATUS.md, docs/research_scope.md, docs/data_access_and_publication.md and current source records before continuing.

- Execute one research module at a time, serially. Do not spawn subagents by default.
- First-round evidence must be collected anew. Do not open prior market reports, prior GitHub outputs or the older macro document to anchor the conclusions.
- Public research, routine downloads permitted by the source, code changes and checks are authorized. Do not repeatedly request confirmation for those actions.
- Do not contact brokers, schools or banks, make payments, or change research scope without applicable user authorization.
- Record exact dataset vintage, observation period, geography, product definition, retrieval date, source URL and transformations.
- Missing is not zero. Unavailable financing records are not proof of all-cash purchases. Building form and legal ownership are separate.
- Keep household finances, private interviews, personal quotes, credentials and private Drive links out of this repository.
- Public accessibility is not a redistribution license. Follow source-specific access rules; unknown raw-data rights default to link-only publication.
- Keep raw bytes and fingerprint in the designated private Drive archive when suitable. Public standardized data need a documented publication basis.
- Persist a dated independent B conclusion before accessing household A or prior B conclusions. Private A/C integration stays outside the public repo.
- After each module update STATUS.md with actual artifacts, checks, unresolved gaps and one next action. Stage completion is not whole-project completion.
- New code must be runnable from documented commands. Verify important arithmetic and geography independently; repeatability alone does not establish causal validity.
- Use Chinese, explain mechanisms and counterevidence, and avoid a false precision forecast or universal school ranking.
